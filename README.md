# About
Adhoc notebook to fetch data from large amount of presigned S3 urls

These S3 urls contain dbt artifacts such as the manifest.json files generated by customers during common dbt operations like run, build, and seed

# Purpose
There is interest in mapping model invocations to the Fully Qualified Names (FQNs) for customer models to investigate and understand how a consumption-based billing model would impact existing users and use cases.

That mapping does not seem to currently exist in any location except for the manifest.json files generated at runtime. 

This repository will take in a list of S3 URLs and make GET request to each bucket, extract the manifest.json files, and in theory, build a dataset comprised of unique model id and model FQN.

This workflow is adhoc in nature and will likely not be productionized, at least not in this form, and for that, will likely circumvent best practices in many ways. Ultimately, it will likely require a direct push to Snowflake through the provided Python client library.

Once in Snowflake the mapping will be used to run analyses on billing patterns and inform the evolution of dbt's billing strategy.

# Usage
Ensure that a txt file of \n delimited presigned S3 urls is present in this directory, and that a directory exists to capture the `manifest.json` files downloaded from those presigned urls. This repo comes configured to use a directory, `data`, but the option to rename is available in the code; just make sure that if you do rename it in the code you create the corresponding directory here. It may also behoove you to add the name of whichever directory you create to `.gitignore` if future commits are expected.
